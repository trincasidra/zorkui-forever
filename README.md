# zorkui-forever
A port of ZorkUI 8.0 ([git](https://github.com/zorker/rothui/tree/master/wow8.0) / [wowinterface](https://www.wowinterface.com/downloads/info24252-ZorkUI.html)) for WoW Forever.

Unit frames are based on oUF ([wowinterface](https://www.wowinterface.com/downloads/info9994-oUF.html)), so you will need to install that separately.
